◆ ActualizarCliente()

bool Library.Clases_principales.Usuario.ActualizarCliente ( int clienteId,
object dato )

Actualiza la información del registroCliente de un cliente identificado por su ID, agregando o modificando datos según el tipo del objeto proporcionado.

Parameters
clienteIdIdentificador único del cliente a actualizar.
datoObjeto que contiene la información a actualizar. Puede ser una instancia de Mensaje, Llamada, Precio, Reunion o Venta.
Returns
true si el cliente fue encontrado y la actualización se realizó correctamente;
false si no se encontró el cliente o el tipo de dato no es válido.

Este método busca el cliente por su identificador mediante BuscarClientePorId. Dependiendo del tipo del objeto dato , actualiza diferentes colecciones o propiedades dentro del registro del cliente:

  • Mensaje → Se agrega a la lista de mensajes enviados.
  • Llamada → Se agrega a la lista de llamadas realizadas.
  • Precio → Se registra el nuevo precio asociado.
  • Reunion → Se asigna la reunión actual del cliente.
  • Venta → Se agrega a la lista de ventas realizadas.
