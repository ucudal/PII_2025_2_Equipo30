bool Library.Clases_principales.Vendedor.AsignarClienteAotroVendedor ( Cliente cliente,
Vendedor otroVendedor )

Asigna un cliente de este vendedor a otro vendedor.

Parameters
clienteInstancia del Cliente que se desea reasignar.
otroVendedorInstancia del Vendedor al cual se le asignará el cliente.
Returns
true si el cliente fue reasignado correctamente;
false si el cliente o el vendedor destino son nulos,
o si el cliente no pertenece al vendedor actual.

El método realiza los siguientes pasos:

  1. Verifica que el cliente y el otro vendedor existan.
  2. Comprueba que el cliente esté asignado a este vendedor.
  3. Elimina al cliente de la lista actual.
  4. Agrega al cliente a la lista de clientes del otro vendedor.
